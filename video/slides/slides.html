Security by Architecture

Structural guarantees, not polite prompts

  • One whitelist exit: sanitizeForCloud() — originals aren't in any schema
  • Least privilege: writer has no tools, auditor can only scan
  • Restore returns a local path, never content
  • The claim is an executable test: no tool response contains original PII
